# AGENTS.md - guidance for agents in this repo

- **Product:** a student submits one PDF with either the entire document or one selected page range, OR one ordered image group, and gets one self-contained HTML guide generated by OpenRouter under the Diagram-design system. PDFs and images cannot mix in one Forge action; initial Forge has no user prompt.
- **Runtime:** requests go through OpenRouter, use the exact model `deepseek/deepseek-v4.1-flash`, and are restricted to OpenRouter's `deepseek` provider with no provider fallback.
- **Pipeline:** ingest -> copy or reuse the source in local storage -> extract one source unit (one PDF selection or one image group) -> generate under Diagram-design -> validate -> present. Every Forge action creates a new guide/history entry, including failures; retry replaces a failed entry when successful.
- **Output contract:** the downloadable HTML file and the in-app download view are the same artifact - one render path, and the in-app view must match the file exactly. Artifacts are self-contained: no CDN or other network access is needed to open them.
- **Diagram-design is content, not styling:** it constrains generated HTML and is the single biggest quality lever; prompts and design-system sources are versioned first-class artifacts.
- **Source storage:** matching source content reuses one local source copy. A source copy is removed automatically when no guide references it; deleting the original source file must not break saved guides.
- **Excluded from v1:** Codex ACP, OCR, chat, settings, and custom user prompts. Do not add additional provider choices, parser, or multi-range behavior unless the user explicitly changes the product scope.
- Never commit student material, extracted text, or generated artifacts.
- **Remaining undecided:** accounts, packaging, and other product behavior not explicitly decided by the user - ask rather than assume.
- **Toolchain:** backend tests `uv run pytest -q`; backend lint `uv run ruff check .`; desktop tests `npm test`; desktop build `npm run build` from `desktop`. Use `uv` for Python and `npm` for Node.
- **Git:** do not push, commit, rebase, or alter git config unless explicitly asked.
- **Subagents:** When launching any subagent through the Codex harness for this repository, always use model `gpt-5.6-luna` at max reasoning effort.
